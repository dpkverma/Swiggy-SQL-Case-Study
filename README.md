# 🍔 Swiggy SQL Business Analysis — Case Study

A SQL-based business analysis case study on Swiggy's operational database, built as part of the **WSCube Tech DAMP Cohort-6** program. The project answers real-world business questions around customer behavior, restaurant performance, and delivery operations using **MySQL**.

---

## 📌 Project Overview

Swiggy generates data across customers, restaurants, orders, and delivery partners every day. This project simulates a business analyst's role at Swiggy — using SQL to answer 13 real business questions that support marketing, customer retention, restaurant partnerships, and delivery operations decisions.

Each query in this project is framed around a **business problem** and paired with a **business insight**, rather than being a standalone technical exercise.

---

## 🗂️ Database Schema

The analysis is performed on a database named `SwiggyDB` with the following tables:

| Table | Description | Key Columns |
|---|---|---|
| `customers` | Registered platform users | `customer_id`, `name`, `city` |
| `restaurants` | Restaurant partners on the platform | `restaurant_id`, `name`, `city`, `rating` |
| `orders` | Orders placed by customers | `order_id`, `customer_id`, `restaurant_id`, `order_date`, `total_amount`, `status` |
| `deliverypartners` | Delivery agents | `partner_id`, `name` |
| `orderdelivery` | Mapping of orders to delivery partners | `order_id`, `partner_id` |
| `deliveryupdates` | Delivery status tracking per order | `order_id`, `status` |

> 📝 **Note:** This repo currently contains the analysis queries only. Table creation (`CREATE TABLE`) and sample data (`INSERT`) scripts are being added — see [Roadmap](#-roadmap) below. Until then, this schema reflects the structure inferred from the queries.

## ❓ Business Questions Answered

| # | Business Question |
|---|---|
| 1 | Which customers live in Delhi? |
| 2 | What is the average restaurant rating in Mumbai? |
| 3 | Which customers have placed at least one order? |
| 4 | How many orders has each customer placed? |
| 5 | What is the total revenue generated by each restaurant? |
| 6 | Which are the top 5 highest-rated restaurants? |
| 7 | Which customers have never placed an order? |
| 8 | How many orders has each Mumbai customer placed? |
| 9 | Which orders were placed in the last 30 days? |
| 10 | Which delivery partners completed more than 1 delivery? |
| 11 | Which customers ordered on exactly 3 different days? |
| 12 | Which delivery partner served the most unique customers? |
| 13 | Which same-city customers ordered from the same restaurant on different dates? |

Full queries with business context and insights are in [`Swiggy_SQL_Business_Analysis_Deepak.sql`](./Swiggy_SQL_Business_Analysis_Deepak.sql).

---

## 💡 Key Insights

- **Customer engagement** can be segmented into active, moderately active (3-day orderers), and dormant (never ordered) groups — each needing a different retention strategy.
- **Revenue is concentrated** among a subset of top-performing restaurants, useful for prioritizing partnership decisions.
- **Delivery partner performance** varies significantly by both delivery volume and unique customer reach, which can inform incentive design.
- **Recent order trends** (last 30 days) help track short-term platform demand.

## ▶️ How to Run

1. Install MySQL / MySQL Workbench.
2. Create the `SwiggyDB` database and its tables (see [Roadmap](#-roadmap) for the upcoming schema script).
3. Open `Swiggy_SQL_Business_Analysis_Deepak.sql` in MySQL Workbench.
4. Run `USE SwiggyDB;` followed by each query section-by-section.
